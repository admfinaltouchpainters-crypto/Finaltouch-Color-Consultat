IA que acha as paredes sozinha

Com a chave, você só joga a foto e as 3 opções saem prontas. Como pegar a chave (1 minuto): entre em aistudio.google.com com uma conta Google → Get API key → Create API key → copie e cole aqui. Gerar imagens pode exigir faturamento ativo na conta Google (custa centavos por foto). A chave fica salva só neste aparelho.
